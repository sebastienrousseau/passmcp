## Highlights ⭐️

* **Security fix: built with Go 1.26.9**: GO-2026-6599, GO-2026-6600, GO-2026-6603, GO-2026-6605, GO-2026-6607, GO-2026-6608, GO-2026-6609, GO-2026-6610, GO-2026-6611, GO-2026-6612, GO-2026-6613 and GO-2026-6617, standard-library advisories reachable from passmcp, nine of them in `net/http`. Affected versions: v0.0.1 to v0.0.6, all built with Go 1.26.8. Upgrade to this release; there is no workaround.
* **Silence on a bad stdio line is no longer a failure**: the official MCP SDKs ignore an unparsable line on a pipe on purpose, so `protocol.malformed_json` now reports it as info instead of marking a stdio server "Not ready for agents".
* **`initialize` is asked for the way an older client asks**: `protocol.deprecated_features` stops warning that a server serving both protocol generations declares revisions it does not serve.
* **In lockstep with the passmcp family at 0.0.7**, every component released together at one version.
