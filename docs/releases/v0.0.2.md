## Highlights ⭐️

* **The whole family moves together**: every repository now carries one version, and passmcp-lsp and passmcp-census first ship at 0.0.2. `ecosystem.json` moves to schema 2, with statuses that name facts (`released`, `unreleased`, `rejected`).
* **Servers that fail on purpose**: `go run ./examples/servers -list` shows seven deliberately flawed local servers and the check that catches each, so you can see what passmcp finds without pointing it at anybody's real server.
* **A clearer id mismatch**: `protocol.id_echo` now names the id a server sent back, where it used to print a memory address.
