# Coming from another tool

Each guide says what carries over, what is genuinely different, and what
passmcp will not do. None of them requires changing the server; passmcp only
observes.

- [From MCP Inspector](from-mcp-inspector.md) — the interactive
  playground most people try first
- [From a curl script](from-a-curl-script.md) — the hand-rolled
  `initialize` and `tools/call` you keep in a gist
- [From an online playground](from-an-online-playground.md) — a hosted
  page that connects to your server and lists its tools
